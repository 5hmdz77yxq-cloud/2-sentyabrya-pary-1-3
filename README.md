# Мини-графический редактор

## 1. Название и описание задачи
Программа позволяет создавать геометрические фигуры (круги и квадраты) и вычислять их площадь. Реализована на Python с использованием принципов объектно-ориентированного программирования.

## 2. Архитектура проекта
- **Инкапсуляция**: координаты фигур скрыты, доступ через методы get_coords() и set_coords()
- **Наследование**: Circle и Square наследуются от Figure
- **Полиморфизм**: метод calculate_area() переопределён в каждом дочернем классе

## 3. Пример использования
```python
figures = [
    Circle(0, 0, 5),
    Square(10, 10, 4)
]
total = 0
for fig in figures:
    total += fig.calculate_area()
print(total)
